# RTİB Gündem Editörü

RTİB gündem metinlerini haber bloklarına ayıran; ana haber seçimini, haber sıralamasını, veri kartlarını ve resmî döviz kurlarını editör kontrolüne bırakan bağımsız statik uygulama.

## Kullanım

Haber başlığını ilk satıra, içeriği altına yazın. Haberleri boş satırla ayırın. Haberler hazırlandıktan sonra ana haberi seçebilir, sıralamayı değiştirebilir ve veri kartlarını düzenleyebilirsiniz.

## Kontrol

```bash
npm test
```
